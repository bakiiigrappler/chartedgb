      Questions fréquentes

      Je n'ai pas reçu le code de vérification

      Le code arrive en moins d'une minute dans votre messagerie professionnelle. Vérifiez le dossier « Courrier indésirable », puis utilisez « Renvoyer un code ». Au-delà de trois essais, appelez le poste 2433.

      Comment changer de fonction sans me déconnecter ?

      Ouvrez la carte utilisateur en bas de la barre latérale, ou le menu de votre nom en haut à droite, et choisissez la fonction voulue.

      Un dossier a été rejeté : que dois-je faire ?

      Ouvrez le dossier, lisez le motif dans l'onglet « Historique des changements », corrigez la pièce concernée puis prévalidez à nouveau.

      Puis-je signer plusieurs dossiers à la fois ?

      Oui : dans « À signer », cochez les dossiers puis « Signer la sélection ». Un seul code suffit pendant 15 minutes.

      Comment retrouver une page rapidement ?

      Appuyez sur Ctrl K, tapez quelques lettres du nom de la page et validez avec Entrée.
